# Brand logos

Put the two IPHIX logo files in this folder with **exactly** these names:

| File | Used for |
|---|---|
| `IPHIX Logo.png` | **Main logo**: site header, footer, PDF receipts, link previews |
| `IPHIX Logo Icon.png` | **App logo**: browser tab icon, phone home-screen icon ("Add to Home Screen") |

No code changes or restart are needed. Until the files are here, the site shows its built-in text logo.
